## A1 · 지면 가시에 가장 먼저 맞을 몬스터는?

![다리 위의 B는 월드 높이가 가장 높지만 발밑 지형까지의 거리는 1m다.](./Image%20Archive/a1.svg)

| 항목 | 내용 |
| --- | --- |
| **입력** | 발끝 높이와 발밑 지형 목록은 A가 5와 [0], B가 9와 [8,0], C가 3과 [1]이다. |
| **구현할 내용** | 각 몬스터 바로 아래의 첫 지형에서 같은 속도로 가시가 솟는다. 가장 먼저 닿는 몬스터와 수직 거리를 반환한다. 발밑에 지형이 없으면 후보에서 제외한다. |

**통과 기준**

- [ ] A·B·C까지 각각 5·1·2m다. **B, 1m**를 반환한다.
- [ ] B의 지형 목록을 [0,8]로 뒤집어도 결과가 같다.
- [ ] 모든 지형 목록이 비면 대상 없음이다.

## A2 · 대시 중 어느 발판에 처음 착지할까?

![내려가는 경로는 높은 A의 왼쪽을 지나 B에 처음 닿는다.](./Image%20Archive/a2.svg)

| 항목 | 내용 |
| --- | --- |
| **입력** | 발 위치 (0,5)→(6,−1). 발판의 높이와 x 범위는 A가 4와 [3,5], B가 2와 [2,4], C가 0과 [4,6]이다. |
| **구현할 내용** | 한 프레임 안에서 발이 직선으로 움직인다. 위에서 아래로 처음 통과한 수평 발판과 교점을 구한다. 끝점 접촉도 포함한다. |

**통과 기준**

- [ ] **B의 (3,2)**에 착지한다. 목록 순서를 바꿔도 같다.
- [ ] 같은 경로를 거꾸로 이동하면 착지하지 않는다.
- [ ] B의 범위를 [3,4]로 줄이면 왼쪽 끝에 착지한다.

## A3 · 조준 보정은 누구를 골라야 할까?

![화면 거리 동률인 B와 C는 월드 거리로 비교한다.](./Image%20Archive/a3.svg)

| 항목 | 내용 |
| --- | --- |
| **입력** | 조준점 (400,300), 반경 50px. A=(403,300)은 벽 뒤, B=(420,300)는 월드 거리 12m, C=(400,320)는 7m다. 셋 모두 카메라 앞이다. |
| **구현할 내용** | 화면 반경 안에서 보이는 적 중 조준점과 가장 가까운 적을 고른다. 화면 거리가 같으면 월드 거리가 짧은 적을 선택한다. |

**통과 기준**

- [ ] B와 C는 모두 20px 떨어져 있으므로 **C**를 고른다.
- [ ] 카메라 뒤에서 화면 중앙에 투영되는 적을 추가해도 C다.
- [ ] 모두 가려졌거나 범위 밖이면 대상 없음이다.

## A4 · 레이저의 끝을 스친 캐릭터도 맞을까?

![원의 중심이 끝점에서 대각선으로 더 멀어지면 선분과 원이 떨어진다.](./Image%20Archive/a4.svg)

| 항목 | 내용 |
| --- | --- |
| **입력** | 레이저 선분 (0,0)→(4,0), 캐릭터 반지름 1. 중심 후보는 (2,1), (5,0), (5,1)이다. |
| **구현할 내용** | 두께 없는 선분과 원이 겹치거나 접촉하는지 판정한다. 레이저 길이가 0인 경우도 처리한다. |

**통과 기준**

- [ ] (2,1)은 몸통에, (5,0)은 끝점에 닿아 피격된다.
- [ ] (5,1)은 끝점까지 거리가 √2여서 빗나간다.
- [ ] 레이저가 원점 한 점이고 캐릭터 중심이 (0.5,0)이면 피격된다.

## A5 · 발소리는 어느 쪽에서 들릴까?

![플레이어만 반대 방향으로 돌아서면 같은 음원의 좌우가 바뀐다.](./Image%20Archive/a5.svg)

| 항목 | 내용 |
| --- | --- |
| **입력** | 플레이어 (0,0), 정면 (0,1), 음원 (3,2). 월드 +x는 오른쪽, +y는 위다. |
| **구현할 내용** | 플레이어가 보는 방향을 기준으로 소리가 왼쪽·오른쪽·중앙 중 어디에 있는지 반환한다. 정면과 정후방은 중앙이다. |

**통과 기준**

- [ ] 예시는 **오른쪽**이다. 정면을 (0,−1)로 바꾸면 **왼쪽**이다.
- [ ] 둘의 위치에 동시에 (10,20)을 더해도 결과가 같다.
- [ ] 정면이 (0,1)일 때 음원 (0,3)과 (0,−3)은 모두 중앙이다.

## A6 · 넉백으로 벽에 부딪히면 어디까지 밀릴까?

![최종 중심은 벽에서 반지름만큼 왼쪽에 있다.](./Image%20Archive/a6.svg)

| 항목 | 내용 |
| --- | --- |
| **입력** | 벽 x=10, 캐릭터 반지름 0.75, 시작 중심 x=8, 예정 중심 x=12. 캐릭터는 벽 왼쪽에 있다. |
| **구현할 내용** | 수평 이동 후 원이 벽을 뚫지 않는 최종 중심을 구한다. 벽에서 멀어지는 이동도 처리한다. |

**통과 기준**

- [ ] 최종 중심은 **x=9.25**다.
- [ ] 벽에 닿은 x=9.25에서 x=8로 이동하면 8까지 간다.
- [ ] 8에서 9로만 밀리면 그대로 9에 멈춘다.

## A7 · 포탑이 이번 프레임에 발사해도 될까?

![회전 뒤 8도에 도달한 프레임에서 목표 10도와의 차가 허용 범위로 들어온다.](./Image%20Archive/a7.svg)

| 항목 | 내용 |
| --- | --- |
| **입력** | 현재 350°, 목표 10°, 최대 각속도 60°/s, dt=0.1초, 발사 허용 오차 5°. |
| **구현할 내용** | 짧은 방향으로 회전한 뒤 새 각도와 발사 가능 여부를 구한다. 각도는 [0°,360°)로 표시하고 목표를 지나치지 않는다. |

**통과 기준**

- [ ] 세 프레임의 결과는 **356°·불가 → 2°·불가 → 8°·가능**이다.
- [ ] 358°에서 1°를 향하면 한 프레임 뒤 정확히 1°다.
- [ ] 회전 후 각도 차가 정확히 5°면 발사 가능이다.

## A8 · 낮은 천장 아래에서 일어설 수 있을까?

![천장과 몸체가 내부에서 겹치는 경우와 면에서만 닿는 경우를 비교한다.](./Image%20Archive/a8.svg)

| 항목 | 내용 |
| --- | --- |
| **입력** | 캐릭터 x 범위 [2,3], 발 높이 0, 기립 높이 2. 천장 x 범위 [2.5,4], 아랫면 y=1.8. |
| **구현할 내용** | 발은 고정하고 충돌체를 위로 늘린다. 축 정렬 사각형의 내부가 겹치면 기립을 막고 면 접촉만 있으면 허용한다. |

**통과 기준**

- [ ] 천장과 일부가 겹쳐 **기립 불가**다.
- [ ] 천장 아랫면이 y=2라면 접촉만 하므로 기립 가능이다.
- [ ] 천장 x 범위가 [3.1,4]이면 아랫면이 y=1.8이어도 가능하다.

## A9 · 독 피해가 몇 번 들어가야 할까?

![0.4초와 1.6초 사이에는 0.5초, 1초, 1.5초의 세 피해 시각이 있다.](./Image%20Archive/a9.svg)

| 항목 | 내용 |
| --- | --- |
| **입력** | 이전·현재 누적 시간, 피해 주기 0.5초, 만료 시각 2초. |
| **구현할 내용** | 이번 프레임에서 새로 지난 피해 시각 개수를 반환한다. 적용 순간은 제외하고 만료 시각은 포함한다. |

**통과 기준**

- [ ] 0.4→1.6초에 **3회**, 1.6→2.3초에 **1회**, 그 뒤에는 0회다.
- [ ] 0→0.5와 0.5→1.0은 각각 한 번이다.
- [ ] 0→2.3초를 한 번에 처리하면 4회다.

## A10 · 폭발이 어느 적에게 가장 큰 피해를 줄까?

![파란 구간은 적의 단면이다. B의 가장자리가 폭발 중심에 더 가깝다.](./Image%20Archive/a10.svg)

| 항목 | 내용 |
| --- | --- |
| **입력** | 폭발 중심 (0,0), 범위 5m, 최대 피해 100. A는 중심 (4,0)·반지름 0.5, B는 중심 (5,0)·반지름 2다. |
| **구현할 내용** | 폭발 중심에서 원형 충돌체까지의 최단거리로 피해를 구한다. 내부에서는 최대 피해, 바깥은 5m까지 선형 감소하며 이후는 0이다. |

**통과 기준**

- [ ] A는 **30**, B는 **40**이므로 B를 고른다.
- [ ] 중심 (0.5,0)·반지름 1인 적은 피해 100이다.
- [ ] 중심 (6,0)·반지름 1인 적은 피해 0이다.
