## 13주 · 카메라와 곡선

![베지에 레일의 표식](./figures/week-13.svg)

*같은 시간 간격으로 찍은 표식 사이의 거리를 비교해 카메라 속도의 변화를 찾는다.*

### 1일차 · 두 가지 보간

시작 0, 목표 10이다. 매 프레임 현재 위치에서 남은 거리의 50%를 이동하면 두 번 뒤 위치는? 시작·끝을 고정하고 보간 비율을 0.5, 1로 지정할 때와 비교하라.

<details>
<summary>손풀이 검산</summary>

반복 추적은 5, 7.5이고 고정 구간 보간은 5, 10이다.

</details>

### 2일차 · 이차 베지에

A=(0,0), B=(0,4), C=(4,4)다. t=0.5에서 AB와 BC를 각각 선형 보간하고 그 두 점을 한 번 더 보간하라.

<details>
<summary>손풀이 검산</summary>

중간점은 (0,2), (2,4)이고 곡선 위의 점은 (1,3)이다.

</details>

### 3일차 · 반감기 카메라

| 입력 | 구현할 내용 |
| --- | --- |
| 시작 위치 0, 정지 목표 10, 반감기 h=0.5초, 30fps와 120fps | 프레임별 보간 비율 1−2^(−dt/h)를 적용하고 같은 시각의 위치를 비교한다. |

**통과 기준**

- [ ] 0.5초에는 5, 1초에는 7.5로 두 실행이 일치한다.

### 4일차 · 곡선 레일

| 입력 | 구현할 내용 |
| --- | --- |
| 이차 베지에 제어점 A=(0,0), B=(0,4), C=(4,4), t∈[0,1] | t에 따른 카메라 위치를 선으로 그리고 시작·중간·끝을 표시한다. |

**통과 기준**

- [ ] 시작 (0,0), 중간 (1,3), 끝 (4,4)를 지난다.
- [ ] 중간 제어점 B는 통과하지 않는다.

### 5일차 · 속도 측정

| 입력 | 구현할 내용 |
| --- | --- |
| 같은 곡선, t=0, 0.25, 0.5, 0.75, 1 | 이웃한 표식 사이 직선거리를 출력해 같은 시간 동안 움직인 거리를 비교한다. |

**통과 기준**

- [ ] 순서대로 약 1.768, 1.458, 1.458, 1.768이다.
- [ ] 양 끝 구간에서 더 멀리 간다.

### 6일차 · 거리로 재생

| 입력 | 구현할 내용 |
| --- | --- |
| 같은 곡선, 누적 거리표용 표본 1,001개, 재생 구간 20개 | 누적 이동거리에서 t를 역으로 찾는다. 균일 거리 재생과 균일 t 재생의 구간 길이 편차를 비교한다. |

**통과 기준**

- [ ] 같은 양 끝점을 지나며 20개 구간 길이의 최대값과 최소값 차이가 균일 t 방식보다 작아진다.

#### 이번 주 실험 기록

## 14주 · 두 관절 애니메이션

![같은 목표에 닿는 두 자세](./figures/week-14.svg)

*손과 어깨의 위치를 고정해도 팔꿈치의 굽힘 방향은 두 가지다.*

### 1일차 · 순운동학

위팔 길이 2, 아래팔 길이 1, 어깨는 원점이다. 어깨의 월드 각도 90°, 팔꿈치의 상대 각도 −90°라면 팔꿈치와 손은 어디인가?

<details>
<summary>손풀이 검산</summary>

팔꿈치 (0,2), 손 (1,2). 아래팔의 월드 각도는 0°다.

</details>

### 2일차 · 역으로 각도 구하기

두 뼈 길이가 각각 1이고 목표가 (1,1)이다. 코사인 법칙으로 두 뼈 사이 상대 회전의 크기를 구하고 가능한 팔꿈치 두 곳을 그려라.

<details>
<summary>손풀이 검산</summary>

상대 회전 크기 90°. 팔꿈치가 (1,0)이거나 (0,1)이면 손이 목표에 닿는다.

</details>

### 3일차 · 각도로 팔 그리기

| 입력 | 구현할 내용 |
| --- | --- |
| 원점의 어깨, 뼈 길이 2와 1, 어깨·팔꿈치 각도 (90°,−90°) 및 (0°,0°) | 상대 각도를 누적해 팔꿈치와 손의 월드 위치를 계산하고 팔을 그린다. |

**통과 기준**

- [ ] 첫 예제의 손은 (1,2), 두 번째 손은 (3,0)이다.
- [ ] 뼈 길이는 일정하다.

### 4일차 · 목표를 짚는 팔

| 입력 | 구현할 내용 |
| --- | --- |
| 각 뼈 길이 1, 어깨 (0,0), 목표 (1,1)과 (2,0) | 목표에서 관절 각도를 역으로 구하고 순운동학에 다시 넣어 손 위치를 확인한다. |

**통과 기준**

- [ ] 목표 (1,1)에서 손도 (1,1)에 도달한다.
- [ ] 목표 (2,0)에서는 팔이 일직선이다.

### 5일차 · 도달 범위

| 입력 | 구현할 내용 |
| --- | --- |
| 뼈 길이 2와 1, 목표 (4,0), (0.3,0), (0,0) 순서 | 목표 거리를 도달 가능한 구간으로 제한한다. 방향이 없는 원점 입력에는 직전 목표 방향을 사용한다. |

**통과 기준**

- [ ] 손의 원점 거리는 차례로 3, 1, 1이다.
- [ ] 팔 길이가 다르면 어깨 바로 앞에도 닿지 않는 영역이 생긴다.

### 6일차 · 팔꿈치 전환

| 입력 | 구현할 내용 |
| --- | --- |
| 두 뼈 길이 1, 어깨 (0,0), 목표 (1,1) | 팔꿈치 굽힘 부호를 전환해 두 자세의 어깨·팔꿈치·손을 겹쳐 그린다. |

**통과 기준**

- [ ] 팔꿈치는 서로 다른 두 점에 있고 손은 모두 (1,1)에 있다.
- [ ] 두 결과 모두 뼈 길이 1을 유지한다.

#### 이번 주 실험 기록

- **실행 화면** · 여기에 캡처를 붙이거나 실행 로그를 인용한다.
- **발견한 점** · 같은 목표에서 팔꿈치 위치는 어떻게 달라졌나?

## 15주 · 빛과 카메라 시야

![시야 경계에 걸친 구](./figures/week-15.svg)

*구 전체가 바깥인 경우만 제외한다. 일부라도 보이면 그린다.*

### 1일차 · 방향광 밝기

표면에서 광원을 향하는 단위 방향 L=(0,1,0)이다. 단위 법선이 위, 옆, 아래를 향하는 세 표면의 밝기를 max(0,N·L)로 구하라.

<details>
<summary>손풀이 검산</summary>

밝기는 각각 1, 0, 0이다. 아래를 향한 표면의 음수 내적은 0으로 제한된다.

</details>

### 2일차 · 시야의 경계면

먼저 직교 카메라의 보이는 범위를 x,y∈[−2,2], z∈[1,5]인 상자로 그려라. 각 면에서 내부가 양수가 되는 부호 있는 거리식을 써라.

<details>
<summary>손풀이 검산</summary>

x+2, 2−x, y+2, 2−y, z−1, 5−z. 점 (0,0,3)에서는 여섯 값이 전부 양수다.

</details>

### 3일차 · 법선으로 칠하기

| 입력 | 구현할 내용 |
| --- | --- |
| 광원 방향 L=(0,1,0), L과 0°, 60°, 90°를 이루는 단위 법선 세 개 | 표면에서 광원을 향하는 방향과 법선의 내적으로 선형 회색조 밝기를 계산한다. |

**통과 기준**

- [ ] 선형 밝기 값은 1, 0.5, 0이다.
- [ ] 화면 색 변환 전 수치로 검산한다.

### 4일차 · 절두체 밖 구 제외

| 입력 | 구현할 내용 |
| --- | --- |
| 시야 상자 x,y∈[−2,2], z∈[1,5], 반지름 0.5, 중심 (3,0,3)과 (2.2,0,3) | 안쪽 단위 법선을 가진 여섯 면까지의 부호 있는 거리를 계산해 완전히 밖인 구만 제외한다. |

**통과 기준**

- [ ] 둘째 날 상자에 반지름 0.5, 중심 (3,0,3)은 제외되고 (2.2,0,3)은 보존된다.

### 5일차 · 경계에서 깜박임 찾기

| 입력 | 구현할 내용 |
| --- | --- |
| 같은 시야 상자, 반지름 0.5, 중심 (x,0,3), x=2.0부터 2.6까지 | 구를 이동하고 오른쪽 면까지의 거리와 표시 여부를 함께 기록한다. |

**통과 기준**

- [ ] x=2.5일 때 거리 −0.5로 경계에 접한다.
- [ ] 접촉을 보존하면 x>2.5부터 제외된다.

### 6일차 · 원근 카메라 적용

| 입력 | 구현할 내용 |
| --- | --- |
| 원근 카메라의 여섯 면, 경계에 걸친 구·완전히 밖인 구·내부 구 | 안쪽 단위 법선과 거리 항을 기존 검사에 넣어 카메라를 움직인다. 경계 구와 제외를 결정한 면을 표시한다. |

**통과 기준**

- [ ] 모든 면을 통과한 구는 표시되고, 제외된 구에는 거리 < −반지름인 면이 적어도 하나 표시된다.
- [ ] 물체 중심만 밖인 경우에도 구 일부가 보이면 유지된다.

## 16주 · 길 찾기

![최단 거리와 최소 비용](./figures/week-16.svg)

*늪의 진입 비용이 5일 때 두 걸음 직행보다 네 걸음 우회가 저렴하다.*

### 1일차 · BFS 손으로 추적

상하좌우 이동 비용이 1인 3×3 격자에서 시작 (0,1), 도착 (2,1), 벽 (1,1)이다. 시작에서 같은 거리에 있는 칸끼리 묶어라.

<details>
<summary>손풀이 검산</summary>

거리별 칸 수는 1, 2, 2, 2, 1이고 최단 이동 횟수는 4다.

</details>

### 2일차 · 이동 비용과 추정값

3×2 격자에서 (0,0)→(2,0)으로 간다. 벽은 없고 (1,0) 진입 비용은 5, 다른 칸은 1이다. 직행과 우회 비용, 시작점의 맨해튼 거리를 구하라.

<details>
<summary>손풀이 검산</summary>

직행 6, 우회 4, 맨해튼 거리 2. 최소 한 걸음 비용이 1이므로 이 거리는 남은 비용의 하한이다.

</details>

### 3일차 · 경로 복원

| 입력 | 구현할 내용 |
| --- | --- |
| 3×3 격자, 시작 (0,1), 도착 (2,1), 벽 (1,1), 상하좌우 이동. 추가로 도착 칸도 막은 지도 | BFS로 탐색하며 직전 칸을 기록하고 도착점에서 거슬러 경로를 복원한다. |

**통과 기준**

- [ ] 원래 지도에서는 벽을 피해 4번 이동한다.
- [ ] 막힌 도착점에서는 경로 없음이 반환된다.

### 4일차 · 다익스트라 구현

| 입력 | 구현할 내용 |
| --- | --- |
| 3×2 격자, 시작 (0,0), 도착 (2,0), 늪 (1,0) 진입 비용 5, 나머지 1 | 시작 비용 0에서 다익스트라로 이동 비용과 경로를 구하고 BFS가 고른 경로와 비교한다. |

**통과 기준**

- [ ] 한 줄 우회해 도착하며 총비용은 4다.
- [ ] BFS의 최소 걸음 경로는 직행 2걸음이다.

### 5일차 · A*와 비교

| 입력 | 구현할 내용 |
| --- | --- |
| 앞의 늪 지도와 장애물 없는 20×20 지도(맞은편 모서리 간 이동), 상하좌우 이동 | 맨해튼 거리 h를 사용해 g+h가 작은 칸부터 처리한다. 다익스트라와 확정 칸 수·최종 비용을 비교한다. |

**통과 기준**

- [ ] 최종 최소 비용은 두 알고리즘이 같다.
- [ ] 처리 칸 수는 지도와 동점 처리에 따라 달라지므로 실제 측정값을 남긴다.

### 6일차 · 늪 비용의 전환점

| 입력 | 구현할 내용 |
| --- | --- |
| 3×2 지도, 시작 (0,0), 도착 (2,0), 늪 (1,0) 진입 비용 1, 3, 5. 나머지 1 | 비용별로 직행과 우회 비용을 출력하고 선택된 경로를 그린다. 동률이면 어느 쪽이든 허용한다. |

**통과 기준**

- [ ] 직행 비용은 2, 4, 6이고 우회는 항상 4다.
- [ ] 최솟값은 각각 2, 4, 4다.

## 17주 · 확률과 밸런스

![첫 획득의 누적 확률](./figures/week-17.svg)

*10회 천장을 적용하면 누적 획득 확률이 10회에서 100%에 도달한다.*

### 1일차 · 연속 실패

독립 시행에서 매회 성공 확률 p=0.1이다. 3회 모두 실패할 확률과 그 안에 한 번이라도 성공할 확률을 계산하라.

<details>
<summary>손풀이 검산</summary>

0.9³=0.729, 그 여사건은 0.271이다.

</details>

### 2일차 · 평균과 90% 지점

첫 성공까지 걸린 횟수를 첫 시도부터 1로 센다. p=0.1일 때 평균과 누적 성공 확률이 처음 90% 이상이 되는 정수 횟수를 구하라.

<details>
<summary>손풀이 검산</summary>

평균 1/p=10회. 1−0.9ⁿ≥0.9를 처음 만족하는 n은 22다.

</details>

## 18주 · 절차적 생성

![생성한 섬에서 경로 찾기](./figures/week-18.svg)

*같은 시드로 섬을 재생성하고 두 육지 칸 사이를 걸어서 이동할 수 있는지 확인한다.*

### 1일차 · 시드 재현

작은 난수열 x₀=1, xₙ₊₁=(5xₙ+1) mod 16을 네 번 진행하라. 시드를 2로 바꾸고 첫 값부터 비교하라.

<details>
<summary>손풀이 검산</summary>

시드 1의 다음 네 값은 6,15,12,13이고 시드 2의 다음 값은 11이다. 같은 규칙과 시드는 같은 수열을 만든다.

</details>

### 2일차 · 노이즈와 이웃

한 줄 높이 A=[0,1,0,1,0], B=[0,0.25,0.5,0.75,1]에서 이웃 차이 절댓값의 평균을 구하라. 어느 쪽이 완만한 지형과 비슷한가?

<details>
<summary>손풀이 검산</summary>

A는 1, B는 0.25다. B에서 인접한 높이가 더 천천히 변한다.

</details>

### 3일차 · 섬 지형 생성

| 입력 | 구현할 내용 |
| --- | --- |
| 64×64 격자, [0,1] 범위의 연속적인 2D 노이즈, 지형 시드 | 노이즈 값에서 중심까지의 정규화 거리(중심 0, 가장 가까운 변 1)를 뺀다. 양수인 칸을 육지로 칠하고 시드를 기록한다. |

**통과 기준**

- [ ] 변과 모서리는 바다다.
- [ ] 같은 시드로 생성한 육지 배열은 일치한다.
- [ ] 중심 근처에 육지가 있는 시드 하나를 저장하라.

| --- | --- |
| 생성한 섬의 육지, 최소 간격 3칸, 후보 최대 2,000회, 나무 최대 50개 | 후보 나무와 기존 나무의 거리 제곱을 검사해 배치하고 두 종료 조건 중 하나에 도달하면 멈춘다. |

**통과 기준**

- [ ] 모든 나무가 육지에 있고 모든 쌍의 유클리드 거리 제곱이 9 이상이다.
