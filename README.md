## 한 주 공부하는 법

1. **1~2일차**에는 그림을 보고 손으로 푼 뒤 접혀 있는 검산값을 연다.
2. **3~4일차**에는 표의 입력으로 기능을 구현하고 통과 기준을 하나씩 확인한다.
3. **5~6일차**에는 입력 하나를 바꾸고 결과를 예상한 뒤 실행한다. 주차 끝 기록란에 화면 한 장과 관찰한 차이 한 줄을 남긴다.

단계를 마치면 위 표의 도식을 같은 구도의 실행 화면으로 교체해 보자. 명중점처럼 한순간의 위치가 중요한 장면은 정지 화면으로, 회전이나 카메라 보간처럼 움직임이 중요한 장면은 짧은 GIF로 남기면 차이를 확인하기 쉽다.
