## 7주 · 좌표계와 행렬

## 8주 · 카메라와 투영

![깊이와 화면 위치](./Image%20Archive/week-08.svg)

*같은 옆 변위를 가진 두 점 중 먼 점은 화면 중앙에 더 가깝게 투영된다.*

### 1일차 · 좌표의 여정

카메라가 (0,0,5)에서 −z를 보고 위는 +y다. 원점의 월드 좌표와 뷰 좌표를 쓰고 화면 어디에 보일지 스케치하라.

<details>
<summary>손풀이 검산</summary>

월드 (0,0,0), 뷰 (0,0,−5), 화면 중앙이다.

</details>

### 2일차 · 원근 나눗셈

정사각형 화면, 수직 시야각 90°, 카메라 원점, 전방 −z로 둔다. 뷰 좌표 (1,0,−2), (1,0,−4)의 정규화 화면 x를 구하라.

<details>
<summary>손풀이 검산</summary>

x를 깊이 −z로 나누면 0.5와 0.25다. 깊이가 두 배이면 화면 중앙에서의 변위는 절반이다.

</details>

### 3일차 · 화면에 점 찍기

| 입력 | 구현할 내용 |

| 800×800, 좌상단 원점, 수직 시야각 90°, 원점에서 −z를 보는 카메라, 점 (1,0,−2)와 (1,0,−4) | 뷰·투영 변환 뒤 w로 나누고 화면 좌표로 바꿔 점을 찍는다. 우하단 경계는 (800,800)이다. |

**통과 기준**

- [ ] 둘째 날의 점은 각각 (600,400), (500,400)에 표시된다.

### 4일차 · 클릭 광선 복원

- [ ] 둘째 날 카메라에서 중앙 광선은 (0,0,−1), (600,400)의 광선은 (1,0,−2)를 정규화한 방향이다.

## 9주 · 3D 회전

![두 자세 사이의 회전](./Image%20Archive/week-09.svg)

*SLERP로 90° 회전의 절반을 보간하면 정면도 45° 회전한다.*

### 1일차 · 순서가 다른 회전

오른손 좌표에서 벡터 (0,0,1)을 고정된 월드 x축으로 +90°, 이어 y축으로 +90° 돌려라. 순서도 바꿔라.

<details>
<summary>손풀이 검산</summary>

x→y는 (0,−1,0), y→x는 (1,0,0)이 된다.

</details>

### 2일차 · 축–각과 쿼터니언

+y축 중심 90° 회전을 (x,y,z,w) 순서의 단위 쿼터니언으로 표현하고 +z 단위벡터가 향할 방향을 그려라.

<details>
<summary>손풀이 검산</summary>

q=(0,√2/2,0,√2/2). +z는 +x로 향한다.

</details>

### 3일차 · 목표 자세

| 입력 | 구현할 내용 |
| --- | --- |
| 원점의 포탑, 로컬 정면 +z, 위 +y, 목표 (3,0,0). 목표가 원점인 경우도 검사 | 수평 목표를 향하는 자세를 구해 정면과 위쪽 축을 표시한다. |

**통과 기준**

- [ ] 회전 후 정면은 (1,0,0)이고 위쪽은 그대로다.
- [ ] 목표와 포탑 위치가 같으면 현재 자세를 유지한다.

### 4일차 · 회전 보간

| 입력 | 구현할 내용 |
| --- | --- |
| 시작은 항등 회전, 목표는 +y축 90°, t=0, 0.5, 1 | 최단 호 SLERP로 두 자세 사이를 보간하고 정면 벡터를 출력한다. |

**통과 기준**

- [ ] t=0.5에서 정면은 약 (0.707,0,0.707), t=1에서 +x다.

### 5일차 · 반대 방향 근처

| 입력 | 구현할 내용 |
| --- | --- |
| +y축 회전 +179°와 −179° | 두 자세 사이를 보간하고 시작·중간·끝의 정면을 그려 실제 회전량을 잰다. |

**통과 기준**

- [ ] 총 회전량은 약 2°다.
- [ ] 중간 정면은 −z를 향한다.

### 6일차 · 이동하는 포탑

| 입력 | 구현할 내용 |
| --- | --- |
| 포탑 (2,1,3), 목표 (5,1,3), 로컬 총구 (0,0,2) | 조준 완료 후 월드 총구와 정면을 출력한다. 포탑과 목표를 같은 만큼 옮겨 다시 계산한다. |

**통과 기준**

- [ ] 총구 (4,1,3), 정면 (1,0,0). 같은 변위만큼 포탑과 목표를 옮겨도 정면은 같다.

## 10주 · 도형 충돌

![상자 위의 최근접점](./Image%20Archive/week-10.svg)

*구 중심의 각 좌표를 상자 범위로 제한하면 면이나 모서리 위의 최근접점을 얻는다.*

### 1일차 · 구 두 개

중심 (0,0,0), 반지름 2인 구와 중심 (3,0,0), 반지름 1인 구가 만나는지 제곱거리로 판정하라. 둘째 중심을 (3,1,0)으로 옮기면?

<details>
<summary>손풀이 검산</summary>

처음에는 9=3²로 접촉한다. 이동 뒤에는 10>9로 분리된다.

</details>

### 2일차 · 상자의 최근접점

축 정렬 상자의 각 축 범위가 [−1,1]이다. 점 (2,3,0)에서 상자까지 가장 가까운 점과 거리를 구하라.

<details>
<summary>손풀이 검산</summary>

최근접점은 (1,1,0), 거리는 √5다.

</details>

### 3일차 · 구–구 검사

| 입력 | 구현할 내용 |
| --- | --- |
| 구 A 중심 (0,0,0)·반지름 2, 구 B 반지름 1·중심 (3,0,0), (3,1,0), (0,0,0) | 중심 사이 제곱거리로 접촉을 포함한 충돌 여부를 반환한다. |

**통과 기준**

- [ ] 접촉 true, 이동 후 false, 같은 중심 true다.

### 4일차 · 구–상자 검사

| 입력 | 구현할 내용 |
| --- | --- |
| 각 축 [−1,1]인 상자, 구 중심 (2,3,0), 반지름 2 또는 3 | 구 중심에서 상자의 최근접점을 구해 거리 제곱과 반지름 제곱을 비교한다. |

**통과 기준**

- [ ] 반지름 2는 분리, 3은 겹침이다.
- [ ] 중심이 상자 내부면 거리 0이다.

### 5일차 · 면·모서리·꼭짓점

| 입력 | 구현할 내용 |
| --- | --- |
| 같은 상자, 반지름 1, 중심 (2,0,0), (2,2,0), (2,2,2) | 면·모서리·꼭짓점 방향에서 접촉 여부와 최근접 거리를 기록한다. |

**통과 기준**

- [ ] 거리는 1, √2, √3이며 첫 위치만 접촉한다.

### 6일차 · 격자 후보 추리기

| 입력 | 구현할 내용 |
| --- | --- |
| 한 변 5인 격자, x=1, 1.5, 11, 21에 놓인 반지름 0.4인 구 네 개(y=z=0) | 구가 걸친 모든 칸에 등록해 후보 쌍을 중복 제거한다. 첫 두 중심을 4.9와 5.1로 옮겨 반복한다. |

**통과 기준**

- [ ] 전수 비교는 6쌍, 같은 칸 후보는 1쌍이며 실제 충돌 역시 첫 두 구뿐이다.
- [ ] 두 구를 경계 양쪽 4.9와 5.1로 옮겨도 검출된다.

## 11주 · 삼각형과 연속 충돌

![프레임 사이의 명중](./Image%20Archive/week-11.svg)

*두 프레임 위치를 이은 선분이 표적을 가로지른다. 끝점만 보면 충돌을 놓친다.*

### 1일차 · 무게중심 좌표

A=(0,0), B=(4,0), C=(0,4)로 P=(1,2)를 표현하는 가중치 세 개를 구하라. P=(3,3)도 내부인가?

<details>
<summary>손풀이 검산</summary>

첫 가중치는 A,B,C 순으로 (0.25,0.25,0.5). 둘째는 A 가중치가 −0.5라 외부다.

</details>

### 2일차 · 충돌 시점

한 프레임 동안 총알의 y가 2에서 −3으로 선형 변화한다. y=0을 지나는 구간 비율과 dt=0.02초일 때 충돌 시간을 구하라.

<details>
<summary>손풀이 검산</summary>

비율 0.4, 프레임 시작 후 0.008초다.

</details>

### 3일차 · 광선–삼각형 검사

| 입력 | 구현할 내용 |
| --- | --- |
| z=0에 놓인 삼각형의 xy 꼭짓점 (0,0), (4,0), (0,4). z=1에서 −z로 쏘는 두 광선의 xy는 (1,2), (3,3) | 평면 교점의 무게중심 좌표로 삼각형 내부인지 검사한다. 변과 꼭짓점도 포함한다. |

**통과 기준**

- [ ] (1,2,0)은 명중, (3,3,0)은 평면만 통과한다.
- [ ] 변과 꼭짓점은 명중으로 처리한다.

### 4일차 · 선분으로 검사

| 입력 | 구현할 내용 |
| --- | --- |
| 같은 삼각형, 총알 xy=(1,2), 프레임 내 z 변화 2→−3 또는 2→1 | 이전·현재 위치를 잇는 선분 안에서 최초 명중점과 구간 비율을 구한다. |

**통과 기준**

- [ ] 첫 실험은 구간 비율 0.4에 명중, 두 번째는 표적 전에 멈춰 명중하지 않는다.

### 5일차 · 얇은 표적

| 입력 | 구현할 내용 |
| --- | --- |
| 같은 표적, 시작 (1,2,1), 속도 (0,0,−100)m/s, dt=0.02초 | 프레임 끝점만 검사한 결과와 선분 검사 결과를 같은 화면에 표시한다. |

**통과 기준**

- [ ] 끝점은 z=−1로 표면을 놓친다.
- [ ] 구간 검사는 0.01초에 z=0 명중을 찾는다.

### 6일차 · 시간 간격 바꾸기

| 입력 | 구현할 내용 |
| --- | --- |
| 같은 총알과 표적, dt=0.03초 또는 0.004초 | 각 시간 간격으로 첫 명중까지 진행하고 프레임 내 충돌 비율을 누적 시간에 반영한다. |

**통과 기준**

- [ ] 명중 프레임은 다르지만 둘 다 약 0.01초, (1,2,0)에서 맞는다.

## 12주 · 운동과 충돌 반응

![포물선과 이산 적분](./Image%20Archive/week-12.svg)

*속도를 먼저 갱신하는 적분에서는 같은 시각의 높이가 이론값보다 낮아진다.*

### 1일차 · 포물선 예측

원점에서 속도 (4,5), 중력 (0,−10)으로 쏜다. 공기 저항 없이 0.5초와 1초 뒤의 위치를 계산하라.

<details>
<summary>손풀이 검산</summary>

(2,1.25), (4,0). 0.5초에서 수직 속도는 0이다.

</details>

### 2일차 · 반발계수

바닥의 단위 법선 (0,1), 입사 속도 (3,−4)에서 마찰 없이 반발계수 1과 0.5일 때 반사 속도를 구하라.

<details>
<summary>손풀이 검산</summary>

접선 성분은 3이고 수직 성분만 뒤집혀 각각 (3,4), (3,2)다.

</details>

### 3일차 · 고정 간격 적분

| 입력 | 구현할 내용 |
| --- | --- |
| 원점, 초기 속도 (4,5), 중력 (0,−10), dt=0.1초, 10회 | 충돌을 끄고 속도를 먼저 갱신한 뒤 새 속도로 위치를 갱신한다. |

**통과 기준**

- [ ] 1초 뒤 속도 (4,−5), 위치 (4,−0.5). 이론값과 위치 차이가 난다.

### 4일차 · 바닥에서 튀기

| 입력 | 구현할 내용 |
| --- | --- |
| 초기 y=1, 수직속도 −4, 바닥 y=0, 중력 0, dt=0.5초, 반발계수 0.5 | 충돌점까지 진행하고 속도를 반사한 뒤 프레임의 남은 시간만큼 이동한다. |

**통과 기준**

- [ ] 0.25초에 바닥에 닿고 남은 0.25초를 위로 이동해 마지막 y=0.5, 수직속도 +2다.

### 5일차 · 오차 실험

| 입력 | 구현할 내용 |
| --- | --- |
| 원점, 초기 속도 (4,5), 중력 (0,−10), dt=0.1, 0.05, 0.01초 | 각각 1초간 반암시적 오일러 적분을 수행해 이론값과의 y 오차를 표로 만든다. |

**통과 기준**

- [ ] 오차의 절댓값은 0.5, 0.25, 0.05m다.
- [ ] 이번 적분법과 일정한 중력에서는 간격을 절반으로 줄이면 오차도 절반이 된다.

### 6일차 · 단계 과제 검산

| 입력 | 구현할 내용 |
| --- | --- |
| 클릭 가능한 경사면, 포탑과 총구, 중력 0인 직선탄, 시점·포탑 위치 세 조합 | 표식을 향해 조준을 마친 뒤 발사한다. 총구·발사 방향·최초 명중점을 표시하고 표면 밖 클릭도 시험한다. |

**통과 기준**

- [ ] 표적이 총구 앞에 있고 장애물이 없으면 세 번 모두 표식과 명중점이 일치한다(허용 오차 0.01m). 표면 밖 클릭에서는 발사하지 않는다.

#### 이번 주 실험 기록

- **실행 화면** · 여기에 캡처를 붙이거나 실행 로그를 인용한다.
- **발견한 점** · 시간 간격을 절반으로 줄이자 높이 오차가 얼마나 줄었나?
